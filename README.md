# Norte One Premium Website

Website institucional premium para a **Norte One**, empresa focada em sites premium, inteligência artificial, automações, chatbots, cartões NFC, branding digital e soluções tecnológicas para empresas.

## Stack

- Next.js
- React
- TypeScript
- TailwindCSS
- Framer Motion
- GSAP
- Lucide React

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Estrutura

- `app/`: rotas, layout global, SEO e estilos.
- `components/`: experiência principal da landing page.
- `public/brand/`: ativos da marca Norte One.

## Posicionamento

O visual foi desenhado para transmitir tecnologia premium, autoridade, sofisticação e conversão, com uma linguagem dark luxury, microinteracoes e blocos responsivos.
